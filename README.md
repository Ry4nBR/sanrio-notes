# Sanrio Notes

Sanrio Notes e um bloco de notas web organizado por personagens do universo Sanrio.

## Objetivo

Criar uma aplicacao didatica completa com API REST, interface React e persistencia em arquivo JSON para cadastrar, consultar, editar e excluir notas.

## Tecnologias

- Node.js e Express para a API
- Arquivo JSON para persistencia
- React e Vite para o front-end
- Postman para documentacao e testes da API

## Funcionalidades

- API REST para gerenciamento de notas
- Estrutura planejada para interface responsiva com personagens
- Documentacao local e testes

## Identidade visual

A interface sera composta por uma paleta pastel e por oito personagens: Cinnamoroll, Hello Kitty, My Melody, Kuromi, Pompompurin, Pochacco, Keroppi e Badtz-Maru.

## Como executar

### API

```bash
cd backend
npm install
npm start
```

### Front-end

```bash
cd frontend
npm install
npm run dev
```

Crie os arquivos locais a partir de `backend/.env.example` e `frontend/.env.example`.
